# Diagram sources

The SVG files in the parent folder are generated by the scripts in this folder. `svgkit.py` draws boxes, groups and arrows at fixed coordinates. Each script writes its figures next to this folder.

| Script | Output |
|---|---|
| `context.py` | `system-context.svg` |
| `nodes.py` | `node-services.svg`, `status-flow.svg` |
| `grasp_zones.py` | `grasp-zones.svg` |
| `drivers.py` | `control-path.svg` |
| `workspace_map.py` | `workspace-map.svg`, drawn from `kinova_interface/data/configs/env/workspace_objects.yaml` |

Run a script to regenerate its figures:

```bash
python3 docs/assets/diagrams/src/drivers.py
```

`workspace_map.py` needs `numpy`, `scipy` and `pyyaml`. The other scripts need only the Python standard library.

MkDocs does not publish this folder (`exclude_docs` in `mkdocs.yml`).
