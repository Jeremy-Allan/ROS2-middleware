# Contributing

1. Create a branch from `main` for each change. Name it `feature/<name>`, `fix/<name>` or `docs/<name>`.
2. Open a pull request against `main`. Describe what changed and why.
3. A reviewer approves the pull request before it is merged. The author does not merge it.
4. Keep each pull request to one change.
5. When the behaviour of a node, service, action or configuration file changes, update the matching page of the manual in the same pull request.

The conventions for code, documentation and docstrings are on the page [Contributing](docs/technical/contributing.md) of the manual.
